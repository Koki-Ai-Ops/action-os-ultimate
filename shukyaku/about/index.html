集客整理帳 / 無料β

「何をやるか決める」ための
集客整理ツール。

集客整理帳は、集客案を大量に出すツールではありません。業種と目標から、今日やる1つ・投稿案・次回見ることまでを3分で整理します。

対応：飲食店 / 美容院 / 小売 / その他の小規模サービス
目標：新規客 / リピート / SNS反応 / 予約・申込

なぜ作ったか

店舗の集客では、SNS、口コミ、予約、Google検索など選択肢が増えやすく、結局「今日は何をすればいいか」が決まらないことがあります。そこで、選択肢を増やすのではなく、1つに絞る流れを固定しました。

使い方

  1. 業種を選ぶ
  2. 目標を選ぶ
  3. 「今日やる1つ」を確認する
  4. 投稿案を必要なら編集する
  5. 使う / 見送るを決め、理由を残す
  6. 次回見ることを1つだけ確認する

データと料金

登録・ログイン・決済はありません。入力内容と判断履歴はブラウザ内に保存され、外部への自動投稿も行いません。
