# AI集客アシスタント（静的・無料β）

ビルド不要の静的版です。GitHubにそのままアップロードし、VercelでImportすると公開できます。

## 機能
- 日本語LP
- ログイン不要の3分無料デモ
- 「今日やる1つ / SNS投稿案1つ / 改善ポイント1つ」
- 戦略 / 調査 / SEO / コンテンツ / SNS / 分析 の6担当フロー
- 投稿案の承認 / 却下 / コピー
- 判断履歴をlocalStorageへ保存
- デモ分析画面
- モバイル対応

## 入れていないもの
- 決済
- 契約
- 有料広告
- 外部サービスへの自動投稿
- ログイン
- 架空の売上実績や口コミ

## Vercel
1. GitHubで新規リポジトリを作る
2. このフォルダ内のファイルをアップロード
3. Vercel > Add New Project > Import Git Repository
4. Framework Preset: Other
5. Build Command: 空欄
6. Output Directory: 空欄
7. Deploy
