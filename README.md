# 集客整理帳

**公開版：** https://shukyaku-seiricho.onrender.com/

小さなお店向けに、今日のSNS投稿をひとつ決める無料のWebツールです。業種と目的を選び、「今日やること」「投稿文のたたき台」「投稿後に見ること」を整理できます。

- 飲食店・美容院・小売・その他 × 4目的、計16パターン
- 投稿文の編集とコピー
- 「使う／見送る」の判断とメモをブラウザ内に保存
- 記録をJSONファイルで手動エクスポート／復元（内容と形式を検証し、上書き確認してから端末に保存）
- 判断済み履歴（最大20件）をCSVファイルで手動エクスポート（数式として解釈される入力値は無害化）
- 前回の記録を開き直して編集可能
- 登録・決済・自動投稿・外部API通信なし

## 実装と公開

- アプリのソース：[`site/`](./site/)
- 配信：Render Static Site（GitHub `main` ブランチから自動更新）
- ビルド：不要、HTML / CSS / JavaScript の静的サイト
- 保存先：利用者のブラウザの localStorage。旧公開先や別端末との自動同期はありません。
- 実際に入力する価格・営業時間・予約条件などは店舗側で確認してから利用してください。

[7日間の公開・需要検証計画](./LAUNCH_EXPERIMENT.md) / [フィードバック](https://github.com/Koki-Ai-Ops/action-os-ultimate/issues/1)

コードの修正やリリース時は、公開ページと `app.js`・`styles.css` が配信されているかを確認してください。

## データ保全について

公開「集客整理帳」の入力データはブラウザに保存されるため、別端末への自動同期・サーバーバックアップはありません。端末変更やブラウザデータ消去前に、履歴欄の「記録をJSONで保存する」からエクスポートしてください。書き出したファイルには店名、投稿文、メモが含まれる可能性があるので、第三者に共有しないでください。JSONファイルを選んで手動復元する機能があります。形式・バージョン・各項目・サイズを確認してから上書き確認を表示し、成功するまでは元の記録を変更しません。復元前に現在のデータも別ファイルに保存してください。CSVは分析用の一方向エクスポートで、復元には使えません。公開版への反映状況は、GitHub のデプロイ履歴と実際の公開ページで確認してください。

なお、ルート `index.html` の旧Action OS実験アプリは公開 `site/` と別製品です。両方のバックアップ形式は互換ではありません。
